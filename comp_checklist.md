# Checklist for Competition
Checklists for setting up and configuring the robot at competition.

# System Core Refresh
- [ ] Set Team Number
- [ ] Reload CANCoder Flash

# Swerve Drive Configuration
- [ ] Set all encoder offsets to zero
- [ ] Deploy code and enable so swerves move to position
- [ ] Manually move swerves to desired initial position
- [ ] Record encoder offsets
- [ ] Set swerve drive encoder offset to the negated measured value
